## 当前体验

浅粉与香槟金的手机端请柬，配有缎带、并蒂双 Y 标识、英文花体与中文姓名书法字。电脑上以居中的手机阅读宽度展示。

- **开场短片**：打开页面即准备约 0.93 MB、960×540 的手机版短片，完整准备后点播；保留 19.5 秒完整时长、字幕、原声和结尾定格。下载时显示进度，也可随时跳过或重试。
- **拆开邀请**：短片结束后进入蜡封封面。展开的信纸和信封一同适配屏幕，使用新人指定的城堡合照，保留日期及下方文字。拆信后可停留阅读，再点“走进我们的婚礼”进入正文。
- **配乐与标识**：使用新人提供的《A Thousand Years》钢琴＋小提琴完整版曲目（浅绯色的喵演奏，约 4 分 45 秒），以约 2.3 MB 的手机 AAC 副本播放，原始 MP3 保留。拆信手势中直接开始播放，已准备好的音频副本从本地复用，使用原始音量，不做淡入或额外压低音量；可暂停并保留播放进度，重新拆信从头播放，短片原声与配乐不会叠加。点击双 Y 标识可放大并阅读设计灵感。
- **双册翻阅**：按当前两个文件夹整理为「大婚肖像」30 张、「领证全记」32 张，共 62 张。入口为两本错落摆放的纸质相册，带书脊、纸页、细金线和查看记录。大婚肖像封面日期为2027年01月30日，领证这一册封面日期为2026年11月18日；日期下方均显示书法姓名「李有为 & 谢妍」，替代原英文副标题。小书封与放大的封面保持一致。首次点击只放大封面并停留，再点击放大的封面才进入第一张照片，不自动翻页。「领证全记」保留原指定封面，现对应 2-1.jpg；照片独立按数字编号自然排序，从 1-1.jpg 开始，4-10.jpg 接在 4-9.jpg 后面，最后为 6-1.jpg。左右滑动或点按钮以带弧度、纸背及阴影的卷页切换照片，上一张反向卷回；等目标清晰图准备好后才开始翻页，等待时保留当前照片和加载提示。相册固定近全屏，只有关闭按钮退出，没有双击切换和上下拖动。预览与高清图渐进加载、失败重试和双向首尾循环均保留。
